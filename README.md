A deterministic program that writes one funny line (a single sentence, 110 characters) to `/output/entry.txt` for make.fun's "The One-Line Laugh" bounty: a smart fridge that texts about the milk and judges its owner without ever paying rent.

## Run it

```sh
python3 main.py
```
